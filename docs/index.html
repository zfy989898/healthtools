HealthTools calculators: sources and live demos

This repository holds one module per calculator: the formula, the constants with the published paper they came from, the accepted input ranges, and a pure compute(inputs, constants). The function that runs in the browser is the same one that runs at build time to print the worked examples on each page, so the examples cannot drift away from the code.

Each row links the live calculator, the module that implements it, and the primary source the constants were transcribed from. The one equation documented in more depth, including a reference grid computed by the shipped code, is the Deurenberg age and sex terms.

How a number gets onto a page

Every constant is transcribed from a named paper and re-resolved against PubMed at build time; the build fails if a citation no longer resolves, if a page drops below the word floor, or if a page stops being reachable from the site index in three links. The rules themselves are in lib/gates.mjs, and the written-out version is on the site: how the sources are chosen and checked, who runs this and why, what is collected and the medical disclaimer.

These are arithmetic helpers over numbers you type in. They are not medical advice, and nothing here recommends a dose, a diagnosis or a training decision. Site index: healthtools.icu. Every indexable URL, as a machine-readable list: sitemap.xml. Code: zfy989898/healthtools.
